The Truck Management System is a web-based application designed for a transport company operating across different cities in Pakistan.The system helps efficiently manage trucks, routes, and their assignments, enabling the company to streamline operations and track logistics data.
Objective

The main objective of this system is to:

Manage truck and route information
Assign trucks to specific routes
Track route pricing and fuel consumption
Provide a centralized view of all operations

Technologies
Frontend: Angular / HTML, CSS, Bootstrap
Backend: ASP.NET Core (Web API)
Database: MS SQL Server
ORM: Entity Framework Core
